## Cheat sheet

**Book value per common share**
- (Total equity − preferred claim) ÷ common shares outstanding
- Preferred claim = **liquidation value** (if given, otherwise par) + **cumulative arrears**, current year included
- Noncumulative preferred: no arrears, so deduct liquidation value only
- Use shares *outstanding* (excludes treasury)

**Property dividends**
- Measure at **FV on the declaration date**; ignore later FV changes
- Declaration: Dr Asset / Cr Gain (FV − CV), then Dr RE / Cr Property dividend payable (FV)
- Distribution: Dr Property dividend payable / Cr Asset
- Net RE effect = −carrying value (the gain goes through NI into RE)

**EPS: weighted-average shares**
- Splits and stock dividends: **retroactive** to Jan 1 (and to issuances before them); no time-weighting
- Shares issued for cash, and treasury purchases: weight from the transaction date
- A split after year-end but before the statements are issued also restates the year's EPS
- Shortcut: beginning shares × ratio × 12/12, ± each later issuance or purchase × ratio (if before the split) × months/12

**Ratios (Becker)**
- Days sales in A/R = **ending** A/R ÷ (sales ÷ 365)
- A/R turnover = credit sales ÷ **average** A/R
- Days in inventory = **ending** inventory ÷ (COGS ÷ 365)
- Inventory turnover = COGS ÷ **average** inventory
- Before plugging in, check which column is Jan 1 and which is Dec 31

## Answers & explanations

1. **A.** Claim = 5,000 × $104 + 5,000 × $6 × 3 = $520,000 + $90,000 = $610,000. ($1,800,000 − $610,000) ÷ 50,000 = $23.80. B uses par; C ignores arrears; D ignores both.
2. **B.** Noncumulative preferred builds up no arrears, so only the liquidation claim is deducted.
3. **A.** +$40,000 gain (NI) − $340,000 dividend = −$300,000, which equals the carrying value.
4. **B.** The dividend is measured at FV on the declaration date. Record-date and distribution-date values are ignored.
5. **C.** Restate for the 10% stock dividend: 330,000 × 12/12 + 66,000 × 9/12 − 30,000 × 2/12 = 330,000 + 49,500 − 5,000 = 374,500. A skips the restatement; D ignores the treasury purchase.
6. **B.** Splits after year-end but before issuance are applied retroactively to EPS.
7. **A.** $70,000 ÷ ($1,095,000 ÷ 365 = $3,000) = 23.3. B uses average A/R, C uses beginning A/R, D uses COGS.
8. **C.** $1,095,000 ÷ $80,000 average A/R = 13.7.
9. **B.** $40,000 ÷ ($730,000 ÷ 365 = $2,000) = 20.0. C uses average inventory, D uses beginning inventory, A uses sales. Becker uses ending inventory here; some texts compute 365 ÷ inventory turnover with average inventory instead (verify against your Becker formula sheet).
10. **Delta Corp**
    - a. Dr Land 30,000 / Cr Gain on land 30,000. Then Dr Retained earnings 150,000 / Cr Property dividend payable 150,000.
    - b. No entry.
    - c. Dr Property dividend payable 150,000 / Cr Land 150,000. The $155,000 FV is ignored.
    - d. −$120,000 (+$30,000 gain − $150,000 dividend), which equals the carrying value.
    - e. Claim = 8,000 × $55 + 8,000 × $2.50 = $440,000 + $20,000 = $460,000. ($2,400,000 − $460,000) ÷ 100,000 = **$19.40**.
